# Frontend Application

TanStack Start, React 19, and Vite frontend client.

## Getting Started

### Prerequisites
- Node.js (v20+ recommended)
- npm

### Installation
```bash
npm install
```

### Available Scripts
- `npm run dev`: Starts the Vite dev server at `http://localhost:8080`.
- `npm run build`: Compiles production assets.
- `npm run preview`: Previews production build locally.
- `npm run test`: Runs tests via Vitest.
- `npm run lint`: Runs ESLint analysis.
